# Apiscale

Projeto Integrador desenvolvido no 2º semestre do curso de Desenvolvimento de Software Multiplataforma (DSM).

## Sobre o projeto

O Apiscale é uma plataforma web corporativa com mecânicas de gamificação voltada para o acompanhamento de metas, tarefas e evolução profissional dentro das empresas.

Em muitos ambientes de trabalho, a falta de clareza sobre planos de carreira e o acompanhamento puramente burocrático de atividades acabam gerando desmotivação e pouca integração entre times. 
 O Apiscale busca resolver esse cenário transformando as entregas do dia a dia em uma trilha visual de progresso, com pontuação, níveis, ofensiva de dias consecutivos, conquistas, um mascote que evolui conforme o desempenho do colaborador e um espaço dedicado para equipes.

## Funcionalidades principais

- Dashboard: resumo de pontos acumulados, nível atual, ofensiva diária, tarefas em andamento e progresso do mascote.
- Equipes: visualização dos times em que o colaborador participa, metas coletivas, mural de mensagens da equipe, diretório de colaboradores e criação de novas equipes.
- Mascote: representação visual da evolução do usuário conforme conclui suas atividades.
- Tarefas e metas: acompanhamento de entregas individuais e em grupo.
- Perfil: histórico de desempenho e conquistas desbloqueadas.

## Tecnologias utilizadas

Front-end (pasta frontApiscale):
- React com Vite
- JavaScript, HTML5 e CSS3
- Bootstrap 5 e Bootstrap Icons

Back-end (pasta backApiscale):
- Java com Spring Boot (API REST)
- Banco de dados relacional

Versão inicial (pasta Site):
- HTML5 e CSS3 desenvolvidos no 1º semestre
